## 步骤 3：先过 Python 预备关

请先在 `tau-playground/` 用小文件分别敲一遍下面四组代码。命令形式为：在 `tau-source/` 执行 `rtk uv run python ../tau-playground/文件名.py`。这些片段是 Python 语法练习，不是 Tau 源码。

**① dataclass 与列表：**后面会用 dataclass 写自己的最小消息。`field(default_factory=list)` 给每个实例新列表，避免共享可变默认值。

```python
from dataclasses import dataclass, field

@dataclass
class Message:
    role: str
    blocks: list[str] = field(default_factory=list)

a = Message("user")
b = Message("assistant")
a.blocks.append("Hi")
print(a.blocks, b.blocks)  # ['Hi'] []
```

**② 协程与异步生成器：**不含 `yield` 的 `async def` 调用后得到协程，要 `await`；含 `yield` 的 `async def` 调用后得到**异步生成器**，要 `async for`，不能直接 `await events()`。

```python
import asyncio

async def answer():
    return "你好"

async def events():
    yield "message_start"
    yield "message_end"

async def main():
    print(await answer())
    print([item async for item in events()])

asyncio.run(main())  # 你好；['message_start', 'message_end']
```

**③ 普通 `yield`：**`def numbers(): yield 1; yield 2` 返回普通生成器，用 `for item in numbers()`；它与上面的异步事件流是两种对象。运行 `print(list(numbers()))` 应得到 `[1, 2]`。

**④ 异常与 JSONL：**`try/except` 把一次解析失败变成可处理结果；JSONL 是一行一个 JSON 对象。下例不写文件，真正落盘留到模块 10。

```python
import json

line = json.dumps({"role": "user", "content": "你好"}, ensure_ascii=False)
try:
    record = json.loads(line)
except json.JSONDecodeError as exc:
    print("坏的一行：", exc)
else:
    print(record["content"])  # 你好
```

写文件时明确使用 `path.open("a", encoding="utf-8")`，读取时用 `path.open("r", encoding="utf-8")`。每行单独 `json.loads`，坏行才能定位；不要一次把整个 JSONL 当作一个 JSON 对象解析。

对照 `tests/test_agent_harness.py::test_prompt_appends_user_and_assistant_with_pi_lifecycle` 看 `[event async for event in harness.prompt("Hi")]`：这里消费的是事件流。再读一个 pytest 断言，分清输入、调用与预期。
